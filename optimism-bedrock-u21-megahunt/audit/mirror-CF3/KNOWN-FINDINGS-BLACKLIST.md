# Known-findings blacklist

Use this as a **root-cause** blacklist, not a title blacklist. A new report is only novel if it changes the exploit condition, reaches a sibling/inverse path that the cited fix did not close, or demonstrates a current Immunefi impact that the historical report did not.

## Triage rule

A candidate overlapping this file should name: `(a)` the known family, `(b)` the exact new state/history or inverse direction, `(c)` why the old fix/assumption does not apply, and `(d)` a current in-scope impact. Without all four, blacklist it.
