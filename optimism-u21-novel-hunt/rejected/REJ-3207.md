# REJ-3207 — ZK respected-child / unrespected-parent omission

Hypothesis: a respected ZK game can build on an unrespected parent and become a valid anchor.

Killing fact: v9 snapshots whether the child type is respected before parent validation and explicitly rejects a respected child whose exact DGF parent did not snapshot respected status (`ZKDisputeGame.sol:345-365`). The parent index resolves through the factory, not an attacker-supplied address. ZK game type 10 is unregistered on each of the four production factories checked; the non-ZK sibling game designs do not use this ZK parent graph.

Disposition: Rejected on source and production reachability.
