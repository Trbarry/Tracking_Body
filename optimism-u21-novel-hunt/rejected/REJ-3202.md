# REJ-3202 — Permissionless deletion through current-registry mismatch

Hypothesis: because proof deletion judges a historical game through the portal's current AnchorStateRegistry, an arbitrary caller can delete a still-valid live proof.

Killing fact: deletion requires the stored game to be permanently invalid or blacklisted under the current registry before it deletes storage (`OptimismPortal2.sol:711-725`). On block 26433900, real proof `0x76313a38c7aca313f8a180125773dff4981c9f4f9bf81e134a894444412e6b59` has a nonzero timestamp, an IN_PROGRESS game, and no blacklist; `deleteProvenWithdrawal` reverts `OptimismPortal_DisputeGameNotInvalidated`. Reproduced by `NegativeSpace.t.sol::test_deleteProvenWithdrawal_rejectsLiveNonInvalidatedHistoricalObject`.

Disposition: Rejected as a candidate. Temporal coupling remains PRIM-3203; migration-time re-proof is documented design.
