# REJ-1102 — "L1/L2 relay-budget mismatch after U21 breaks in-flight withdrawals"

Idea: the L2CrossDomainMessenger on OP Mainnet is still v2.2.1 (and some unfinalized real
withdrawals were initiated under an even older formula), so every in-flight withdrawal carries a
`gasLimit` computed with the old L1 relay budgets (reserved 40 000 + buffer 5 000), while the v9
L1CrossDomainMessenger now reserves 135 000 + 15 000 (GasConstants.sol:60,75). Expected failure
modes: (a) at the portal's minimum gas the `hasMinGas` check fails and the message is parked as
failed although the target would have had enough gas; (b) the target receives less than
`minGasLimit`; (c) some withdrawal needs more gas than v8 by a margin that pushes it past the
16 777 216 tx gas cap.

Killing facts:
- On-chain constants: L2CDM `version()=2.2.1`, `RELAY_RESERVED_GAS()=40000`,
  `RELAY_GAS_CHECK_BUFFER()=5000`, `baseGas(0x,0)=310160`; real fixtures f0/f16 have
  `gasLimit = 287624 = 285000 + 16·164` (older formula, no 21 000, no 260-byte overhead).
- (a) For all 25 real messenger fixtures and all injected "ok target" shapes on v9,
  `minGasNoRevert == minGasRelayed` (no FAILEDMSG band at the bottom), incl. the legacy formula
  (cases S1#36,#38,#40; S2 LEG rows up to 300 KB / minGas 1M).
- (b) Per-probe assertion `target-saw-less-than-minGasLimit`: 0 hits (TOk records `gasleft()`;
  minGas 30k / 200k / 1M).
- (c) v9 needs LESS gas than v8 for the same withdrawal: Δ(minGas) = −5 652/−5 653 (no value),
  −14 056 (real value withdrawals), −16 596 (injected value) — `evidence/lane11/gas-boundary-{l1pre,l1}.json`,
  e.g. f0: 502 334 → 488 278; f1 (legacy v0): 1 554 940 → 1 540 884; f5: 712 033 → 706 380;
  f13 (plain 53.5 ETH): 617 043 → 602 986. Cause: the pause check goes portal → lockbox →
  SuperchainConfig instead of portal → SystemConfig → portal.ethLockbox → SuperchainConfig.
  The only shape that needs MORE gas is value → empty account (REJ-1103).
- Slack arithmetic matches: messenger receives ≥ `gasLimit` (+≈39 k from the portal's own 40 000
  allowance); `hasMinGas(minGas, 150000)` needs `minGas·64/63 + 190 000`; old-formula gasLimit
  provides `minGas·64/63 + 285 000 + 16·len`.
