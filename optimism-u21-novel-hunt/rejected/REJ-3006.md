# REJ-3006 — a formatter-sized diff hides another live semantic change

Hypothesis: one of the named small v8→v9 library diffs silently changes old callers.

Killing fact: manual token-level review of every named diff found only two runtime additions:

1. `SafeCall.callWithMinGas` adds absent-account value reserve (`SafeCall.sol:7-9,119-135`). Its only changed-overload caller is changed Portal; unchanged callers use unaffected `send`, `call`, or `hasMinGas` paths.
2. `dispute/lib/Types.clearedGameTypes()` is a new function called only by changed Migrator/Validator (`Types.sol:97-110`).

Burn/Constants and MIPS64Memory are comment/doc changes; RLPReader, Predeploys, GasPayingToken, LibPosition, LibUDT, LibGameArgs, MIPS64/Instructions, PreimageOracle, ProxyAdmin, ProxyAdminOwnedBase, LivenessModule, FeeVault and LegacyMintableERC20 are formatting only. `libraries/Types.sol` and MIPS64Arch/State/Syscalls are byte-identical.

Conclusion: rejected. The two real boundaries are retained separately as PRIM-3005/3006.
