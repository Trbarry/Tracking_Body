# REJ-3004 — DGF prestate update retroactively changes old games

Hypothesis: changing `gameArgs[9]` at U21 forces in-flight games onto a new absolute prestate while retaining old claims/VM state.

Killing facts:

- DGF clones snapshot implementation args into clone immutable calldata during creation (`DisputeGameFactory.sol:174-216`). Getters read fixed offsets (`SuperFaultDisputeGame.sol:828-875`).
- Raw DGF storage changed only the first word of future `gameArgs[9]`, from `0x031ac6…90e1df` to `0x03e5a5…3737c9`; VM/ASR/WETH words were unchanged.
- All 84 sampled pre-U21 in-progress games still return the old prestate; representative game resolves and pays.

Conclusion: rejected. The change affects games created after N, not existing clones.
