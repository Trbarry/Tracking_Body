# REJ-2706 — permissionless zero-bond type-5 instant defender game on OP

Status: Rejected.

Hypothesis: Since OP's factory has a type-5 implementation and zero initialization bond, anyone can create an instantly `DEFENDER_WINS` super game and use it for withdrawals.

Exact killing facts:

- `SuperPermissionedDisputeGame.initialize` requires `tx.origin == proposer()` before setting instant defender status (`packages/contracts-bedrock/src/dispute/SuperPermissionedDisputeGame.sol:51-73`).
- OP's packed type-5 args fix proposer `0xc27ba3E0Fc01567a5E57Ae0c391AA98cECBA5bE0`.
- OP currently respects type 9, so even a proposer-created type-5 game would snapshot `wasRespectedGameTypeWhenCreated == false`.
- The live-fork unauthorized creation reverted in `SuperRootPrimitivesTest.test_type5CreationIsNotPermissionless`.

Soneium note: Soneium respects type 5, but its factory args likewise fix a proposer. This is a privileged trust model, not a permissionless lane-27 exploit.
