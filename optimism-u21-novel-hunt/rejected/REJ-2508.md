# REJ-2508 — delete an already-finalized proof to replay withdrawal

## Idea

`deleteProvenWithdrawal` has no `finalizedWithdrawals` check, so a later challenger result/blacklist might let anyone erase evidence and replay.

## Killing fact

Replay protection is a separate mapping set before target execution (`OptimismPortal2.sol:603-610`). Deletion only clears `provenWithdrawals[hash][submitter]` (`:711-727`). Fork test `test_deletingAlreadyFinalizedProofDoesNotClearReplayProtection` uses a real pre-U21 proof finalized under v9, blacklists its game, deletes its proof, and confirms `finalizedWithdrawals[hash]` remains true while the array length also remains unchanged.

Disposition: Rejected; no replay or double unlock.
