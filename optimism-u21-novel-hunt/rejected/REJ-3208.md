# REJ-3208 — Missing explicit code-length check in portal migration

Hypothesis: `migrateToSharedDisputeGame` checks only nonzero addresses, allowing an EOA/malformed ASR or lockbox to be installed.

Killing fact: the function first requires INTEROP, ProxyAdmin-owner authority, a distinct ASR, nonzero addresses, and lockbox authorization (`OptimismPortal2.sol:528-571`). The supplied lockbox is called before storage mutation; the supplied ASR is subsequently used through typed interface calls, so an EOA cannot complete the operation. A malicious contract could satisfy the interface only when the trusted ProxyAdmin owner deliberately supplies it, reducing this to privileged misconfiguration without a permissionless path.

Disposition: Rejected under the engagement's impact model.
