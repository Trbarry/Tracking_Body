REJ-0109: Games created before U21 break against the upgraded AnchorStateRegistry / DelayedWETH (removed `systemConfig()` getters, new pause routing)

Killing facts:
- `grep systemConfig src/dispute` (v8 and v9): no game contract calls `anchorStateRegistry.systemConfig()` or `weth.systemConfig()`; games use `paused()`, `isGameProper/Finalized`, `respectedGameType`, `getAnchorRoot`, `setAnchorState`, and WETH `deposit/unlock/withdraw`, all present in v4.0.0 / v2.0.0.
- Game implementations are byte-identical before and after U21, so there is no old-impl/new-impl split, only old-args/new-args.
- Empirical: OP `anchorGame` moved from `0x51024A83...` to `0x55A5CFd4...` between N and 26433900; the new anchor was created 1794299939 (before the upgrade) with the old prestate, i.e. a pre-U21 clone completed `closeGame` -> `setAnchorState` against ASR v4.0.0. Same on Ink, Soneium, Unichain (anchor advanced on all four).
- Legacy DelayedWETH proxies (v1.0.0/1.1.0 use `SuperchainConfig.paused()`, v1.5.0 uses `SystemConfig.paused()`) still resolve their pause call: both functions exist after U21.
