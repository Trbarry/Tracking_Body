# REJ-3101 — Real v9 gas can finalize a messenger withdrawal with neither outcome

**Idea.** Find an outer gas value where the portal commits `finalizedWithdrawals=true` but the real L1CDM writes neither `successfulMessages` nor `failedMessages`, making replay impossible.

**Killing fact.** For a real post-U21 type-9 proof and deployed portal/messenger, 64 bounded fuzz cases + 128 deterministic cases + exact binary searches found zero such states. The deterministic classes were 43 reverted/unfinalized, 85 finalized+successful, 0 finalized+failed, 0 finalized+neither. Exact success and relay boundary were both 708,920; at 708,919 the whole call reverted and finalization rolled back. See `mirror/lane-31/GAS_BOUNDARY_RESULTS.md` and `test/MessengerGasBoundary.t.sol`.

**Why.** L1CDM writes a failed outcome before an early return at `/home/user/ethereum-optimism/op-v9.0.0/packages/contracts-bedrock/src/universal/CrossDomainMessenger.sol:256-281`, and v9 portal reverts a failed L1CDM low-level call at `OptimismPortal2.sol:639-653`.

**Coverage limit.** This kills the tested production payload/range, not every possible payload or future gas schedule. The only “neither” reproduction required replacing L1CDM code and is separately recorded as mocked-only PRIM-3106.
