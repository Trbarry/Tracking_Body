# REJ-2108 — Permissionless Utils salt occupancy is a current U21 bounty finding

Hypothesis: PRIM-2104 yields theft, permanent freeze, or protocol-wide outage against the executed U21 state.

Killing fact: All four executed chains already had nonzero ETHLockbox proxies before U21, so `loadOrDeployProxy` loaded them and no attacker-contestable CREATE2 deployment occurred. The 2026-11-16 transaction succeeded and all proxy addresses are final. For a fresh-chain deployment the authorized caller can change its salt mixer; for the timestamp-based migration shape, a collision only blocks that timestamp/attempt. No current in-scope chain that must deploy a missing normal proxy with an immutable salt was identified.

The fork PoC proves address occupancy, not eligible impact. It cannot grant the attacker ProxyAdmin authority over the occupied proxy.

Disposition: Rejected as a candidate under the suppression rule for temporary inconvenience/no eligible impact. Retained as PRIM-2104 for future migration/deployment review.
