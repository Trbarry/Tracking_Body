# REJ-3108 — U21 failed-messenger hardening itself permanently freezes valid funds

**Idea.** Because v9 refuses to finalize when L1CDM reverts, a crafted message that always reverts might remain proven forever, whereas v8 marked it failed.

**Killing fact.** Ordinary target failure does not make L1CDM revert: it sets `failedMessages=true` and returns (`CrossDomainMessenger.sol:284-306`), so the portal finalizes and the message is replayable. L1CDM-level reverts (unsafe target, already-relayed legacy shape, insufficient total outer gas) cause the portal to leave the withdrawal unfinalized/retryable. The U21 notice explicitly documents that a messenger withdrawal that can never be relayed remains proven but unfinalized (`upgrade-21.mdx:193-194`), and the engagement suppression list expressly excludes this documented design on its own (`LANE_CONTEXT.md:216-217`).

No permissionless composition turned this into theft, insolvency, or protocol-wide blocking.
