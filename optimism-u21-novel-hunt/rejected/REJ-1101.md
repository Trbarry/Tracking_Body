# REJ-1101 — "Under v9 a messenger withdrawal can be finalized with NEITHER successfulMessages nor failedMessages recorded at some gas value"

Idea: find any gas value / message shape for which `finalizeWithdrawalTransactionExternalProof`
succeeds on the v9 portal while `L1CrossDomainMessenger` records the message in neither mapping
(unreplayable, value re-locked = lost to the user). Under v8 this class exists (see PRIM-1103).

Killing facts (all executed against the real deployed bytecode on fork `l1`, cold access list):

1. Real fixtures (`test/poc/GasBoundary.t.sol`, `evidence/lane11/gas-boundary-l1.json`): 27 distinct
   real withdrawals (25 messenger incl. 4 legacy v0 messages and 3 post-U21 proofs, 2 plain; f9 is
   unfinalizable). Per fixture: binary search of the minimum non-reverting gas, EVERY gas value in
   ±800 around it, coarse sweep from 0 in 4099-gas steps: 51 316 probes, **0 NEITHER, 0 FAILEDMSG**.
   `minGasNoRevert == minGasRelayed` for every messenger fixture and the revert just below is
   `Error("SafeCall: Not enough gas")` — the portal's `callWithMinGas` floor (OptimismPortal2.sol:627,
   SafeCall.sol:131-146) is the binding constraint; an `OptimismPortal_L1CDMCallFailed` regime does
   not exist for real messages.
2. Injected shapes (`test/poc/InjectedGas.t.sol`, HARNESS `vm.store` of one proven entry, real
   bytecode downstream; `evidence/lane11/injected-gas-l1-{P,S1,S2,S4}.json`): 133 cases — inner target
   ∈ {ok, revert, burn-all-gas, 200 KB return bomb, re-entering, empty account, funded EOA,
   EIP-7702-delegated burn/ok}, minGasLimit ∈ {0, 30k, 200k, 500k, 1M}, value ∈ {0, 1 ETH}, inner
   message 0 … 300 000 bytes, three L2 gasLimit formulas (live L2CDM 2.2.1, legacy
   `285000+16·len+64/63·min`, hypothetical v9 L2). 85 341 probes, **0 NEITHER**, 0 per-probe
   accounting violations (relayed ⇒ target paid exactly value and messenger holds 0; failed ⇒
   messenger holds exactly value; target observed ≥ minGasLimit; no forbidden re-entrant call
   succeeded).
3. Fuzz: `testFuzz_gas_class` (256 runs, real fixtures) and `testFuzz_injected_gas_class`
   (256 runs) on `l1`: pass.
4. Structural reason, confirmed by D4 (`evidence/lane11/diff-l1-D4-failing-messenger.txt`): when the
   messenger call itself reverts (assert on a pre-set failed flag; legacy message already relayed)
   v9 reverts `0x979d93bf OptimismPortal_L1CDMCallFailed` and `finalizedWithdrawals` stays false;
   v8 finalized with `WithdrawalFinalized(success=false)`.

Totals on v9: 136 657 probes over 160 withdrawal shapes, 0 NEITHER.
Coverage limits: gas resolution is exhaustive only within ±150…800 gas of the two boundaries;
between them the sweep is 4 099 / 9 973-gas steps (or 1/400 of the range when no top class
exists). Inner message > 300 KB, minGasLimit > 1M and Amsterdam (EIP-8037) gas rules were not
exercised (Amsterdam cannot be simulated here).
