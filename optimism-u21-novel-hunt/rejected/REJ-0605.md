REJ-0605 — "The deeper v9 pause resolution makes the messenger pause check too expensive for in-flight withdrawals"

Idea: L1CDM.paused() now walks SystemConfig -> Portal -> ETHLockbox -> SuperchainConfig (4 proxies); withdrawals initiated before U21 budgeted relay gas with the old constants.

Killing facts:
- `cast estimate` L1CDM.paused() cold: 77,458 (block 26430858, v8) vs 82,523 (26433900, v9): +5.1k. Portal.paused() cold: 61,587 -> 52,062 (cheaper).
- Inside finalizeWithdrawalTransaction the portal's own `_assertNotPaused()` has already warmed lockbox + SuperchainConfig proxies/impls, so the messenger's check only pays for the cold SystemConfig proxy/impl, as in v8 (measured warm call: 9,165 gas).
- Even if a relay did run out of gas, v9 reverts the whole finalization for L2CDM-sent withdrawals (OptimismPortal2.sol:651-653) so nothing is consumed.
