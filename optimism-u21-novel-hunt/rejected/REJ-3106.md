# REJ-3106 — V9 empty-account reserve is a bounty-eligible withdrawal freeze

**Idea.** The new 183,600 gas reserve for value calls to empty accounts could make previously valid withdrawals permanently unfinalizable.

**Killing fact.** Increasing outer gas finalizes; the behavior is a minimum-gas/estimation change, not a permanent state lock. Source explicitly adds the reserve when value is nonzero and codehash is zero (`SafeCall.sol:95-132`). The pinned L1 does not yet run Amsterdam state-gas rules. The differential used deployed portals but synthetic proof storage: v8 minimum 241,483, v9 419,518; it does not establish a stranded real proof. No direct eligible impact was reproduced, and specific-gas griefing/temporary inconvenience is suppressed.

Kept only as PRIM-3104 for future Amsterdam and estimator composition work.
