# REJ-2406 — Pre-Amsterdam 183,600 reserve permanently blocks value withdrawals

## Idea

Because Amsterdam is not active, v9's added 183,600-gas reserve for value to `codehash==0` could reject otherwise-valid value withdrawals.

## Killing fact

The reserve can make a low-outer-gas attempt revert, but the revert unwinds the Portal finalized bit and Lockbox unlock. A later attempt with sufficient gas remains available. On the pinned current EVM, deployed v9 successfully delivered value to both a truly nonexistent account and an existing funded/code-empty account (`mirror/lane-24/tests/WithdrawalFinalization24.t.sol:192-224`). The branch is exactly `_value != 0 && _target.codehash == 0` (`SafeCall.sol:119-135`), so it does not misclassify `keccak256("")` as zero.

Future Amsterdam execution was not locally simulated and is not claimed.
