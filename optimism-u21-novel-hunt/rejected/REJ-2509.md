# REJ-2509 — pause temporarily makes valid proofs deletable

## Idea

ASR `isGameProper` returns false while paused, so permissionless cleanup during pause might erase proofs that become valid after unpause.

## Killing fact

Deletion never calls `isGameProper`, `isGameClaimValid`, or `paused`; it checks only terminal challenger status and permanent blacklist (`OptimismPortal2.sol:711-725`). A fork test uses the real Guardian path to blacklist a real proof game, then activates the actual lockbox-scoped pause and deletes successfully. The enabling reason remains blacklist, not pause. With pause alone, in-progress/defender deletion reverts.

Disposition: Rejected; no temporary validity predicate enters the delete gate.
