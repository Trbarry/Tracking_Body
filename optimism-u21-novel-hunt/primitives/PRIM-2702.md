# PRIM-2702

PRIM-ID: PRIM-2702 — duplicate/unsorted super-root entries are structurally accepted and chain lookup is first-match

Source contracts: Solidity `Encoding`, `SuperFaultDisputeGame`, `SuperPermissionedDisputeGame`, `OptimismPortal2`; Go `op-service/eth`, `op-node/withdrawals`; Kona interop root codec.

Exact functions: `Encoding.decodeSuperRootProof`; both games' `rootClaimByChainId`; `OptimismPortal2.proveWithdrawalTransaction`; Go `unmarshalSuperRootV1`/`superRootChainOutput`; Rust `SuperRoot::decode`.

Trigger: Supply a correctly sized/versioned super-root preimage containing the same chain ID more than once or IDs out of order.

Attacker-controlled inputs: The complete entry sequence for a permissionless type-9 proposal.

Required state: A game whose extra data commits to that preimage.

State mutation: None in decoding; if created, the game registration described in PRIM-2701 occurs.

External calls: Portal calls `rootClaimByChainId(systemConfig.l2ChainId())`.

Cross-contract dependency: Portal and Go withdrawal tooling both return the first matching entry; canonical Go/Rust constructors sort entries, while their raw decoders do not reject duplicates/order.

Broken or weakened assumption: Canonical ordering and uniqueness are constructor/protocol expectations, not L1 encoding invariants.

Candidate compositions: Find a consumer that selects a later duplicate, sorts before hashing, truncates the chain ID, or otherwise disagrees with the portal's first-match result.

Evidence: `packages/contracts-bedrock/src/libraries/Encoding.sol:308-345`; `.../SuperFaultDisputeGame.sol:806-819`; `.../SuperPermissionedDisputeGame.sol:80-89`; `.../OptimismPortal2.sol:437-450`; `op-service/eth/super_root.go:51-58,103-135`; `op-node/withdrawals/utils.go:248-288`; `rust/kona/crates/protocol/interop/src/root.rs:22-85`; fork test `SuperRootPrimitivesTest.test_type9PermissionlessAndDuplicateChainIdsFirstWins` returned the first of two chain-10 roots.

Confidence: High.

Reason it may be benign: The examined portal/tooling consumers agree on first-match, and the canonical fault-proof transition constructs the next root through `SuperRoot::new` (`rust/kona/crates/proof/proof-interop/src/pre_state.rs:70-100`).
