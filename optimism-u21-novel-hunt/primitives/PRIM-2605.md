PRIM-ID: PRIM-2605 — L1 and L2 INTEROP/CGT feature maps are independent state machines
Source contracts: L1 SystemConfig, L2 L1Block/L1BlockCGT/L2ContractsManager; op-node derivation
Exact functions: SystemConfig.setFeature; L1Block.setFeature; L2ContractsManager._loadFullConfig/_apply; LagoonActivationUpgradeTransactions
Trigger: Privileged L1 migration and consensus-scheduled Lagoon activation occur in their respective domains.
Attacker-controlled inputs: No public setter; L2 depositor/ProxyAdmin/PA-owner are authorized.
Required state: Lagoon activation configuration and dependency set.
State mutation: L1 shared-contract state and L2 predeploy feature state change independently.
External calls: Network upgrade deposit invokes L2 L1Block before the L2CM NUT bundle.
Cross-contract dependency: L2CM reads L2 L1Block, not L1 SystemConfig; off-chain derivation decides whether to inject INTEROP based on timestamp and dependency set.
Broken or weakened assumption: An observer cannot infer L2 feature activation from the L1 SystemConfig flag, or vice versa.
Candidate compositions: Wrong ordering between planned L1 OP+Unichain migration and Lagoon activation; dependency-set mismatch across node implementations.
Evidence: `src/L2/L1Block.sol:69-76,230-258`; `src/L2/L2ContractsManager.sol:170-195,403-428`; `op-node/rollup/derive/lagoon_activation_transactions.go:14-22,80-101`; `op-node/rollup/derive/attributes.go:171-182`; OP L2 passive reads C=false/I=false.
Confidence: High.
Reason it may be benign: Both transitions are privileged/consensus-controlled and the pre-bundle ordering is explicit.
