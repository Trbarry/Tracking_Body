PRIM-ID: PRIM-3001 — immutable game clones over mutable shared singleton proxies
Source contracts: `DisputeGameFactory.sol`, `SuperFaultDisputeGame.sol`, `AnchorStateRegistry.sol`, `DelayedWETH.sol`
Exact functions: `DisputeGameFactory.create`; clone getters `absolutePrestate/vm/anchorStateRegistry/weth`; `resolveClaim`, `resolve`, `closeGame`, `claimCredit`; ASR `paused/isGameFinalized/isGameProper`; DelayedWETH `unlock/withdraw`
Trigger: Upgrade ASR or DelayedWETH in place while games created under the prior implementation are unresolved.
Attacker-controlled inputs: Any caller may progress resolution and claim credit; game creation/root data when the game type is permissionless.
Required state: A clone holds bonds and embeds the proxy addresses in immutable args.
State mutation: Resolution credits are accrued in the clone; unlock records and WETH balances live in the shared DelayedWETH proxy.
External calls: Game → ASR during close; game → DelayedWETH during unlock/withdraw; final ETH call to credit recipient.
Cross-contract dependency: Clone code/args are fixed at creation (`DisputeGameFactory.sol:174-217`), but ASR/DelayedWETH behavior is whatever their proxies implement at call time.
Broken or weakened assumption: A game lifetime historically spanned stable pause/finality/custody behavior.
Candidate compositions: Storage reinterpretation, new pause identifier, changed finality/proper-game test, or WETH withdrawal semantics can freeze/re-route pre-upgrade bonds.
Evidence: v9 `DisputeGameFactory.sol:174-217`; `SuperFaultDisputeGame.sol:673-790,945-1037`; 84 sampled N−1 in-progress games share ASR/WETH. `Lane30InFlightTest.test_realInFlightGameResolvesClosesAndPaysAfterU21` passes on real bytecode.
Confidence: High as a boundary; negative for an active exploit.
Reason it may be benign: U21 preserved addresses/layout/state, and a real old clone paid its entire 0.08 ETH credit.

OLD ASSUMPTION: Shared ASR/WETH behavior is stable for the duration of a fixed clone.
NEW U21 CONDITION: Both shared proxies changed implementation underneath 84 sampled in-progress games.
COMPOSITION POSSIBILITY: A future singleton upgrade can invalidate otherwise immutable game lifecycle assumptions.
REQUIRED ATTACKER CONTROL: None to call lifecycle functions; an exploitable semantic mismatch must already exist in the upgrade.
POSSIBLE IMPACT: Bond freeze/theft; if the same game validity feeds Portal withdrawal proofs, withdrawal liveness.
