PRIM-ID: PRIM-2203 — pause-authority dependency pivot

Source contracts: `SystemConfig`, `OptimismPortal2`, `ETHLockbox`, `AnchorStateRegistry`, `DelayedWETH`, `SuperchainConfig`.

Exact functions: `SystemConfig.paused/setFeature`, `OptimismPortal2.paused`, `ETHLockbox.paused`, `AnchorStateRegistry.paused`, `DelayedWETH.withdraw`, `SuperchainConfig.isLocalOrGlobalPaused`.

Trigger: U21 installs/replays lockbox dependencies; later shared-lockbox migration can repoint them again.

Attacker-controlled inputs: Pause checks are permissionless reads; pause mutations are guardian-only and pointer mutations are privileged.

Required state: ETH_LOCKBOX enabled and nonzero portal/ASR/WETH lockbox references.

State mutation: U21 fills lockbox/ASR/WETH dependency slots; the pause timestamp mappings themselves are unchanged.

External calls: Portal/SystemConfig/ASR/WETH resolve through ETHLockbox to SuperchainConfig.

Cross-contract dependency: The identifier changes from a portal/system-specific reference to the current lockbox address, with global identifier zero as a second authority.

Broken or weakened assumption: Pause state is not intrinsic to the calling contract; changing one dependency pointer changes which mapping key governs withdrawals.

Candidate compositions: A latent pause under the old key; multi-chain shared-lockbox migration; one legacy WETH/ASR left pointing to the old lockbox.

Evidence: `op-v9.0.0/packages/contracts-bedrock/src/L1/SystemConfig.sol:528-576`; `.../ETHLockbox.sol:111-119`; `.../AnchorStateRegistry.sol:135-143`; `.../DelayedWETH.sol:98-108`; all global/portal/lockbox entries in `PAUSE_AND_AUTHORIZATION_MAPPINGS.md`; migrator checks at `OPContractsManagerMigrator.sol:488-555`.

Confidence: High.

Reason it may be benign: All relevant deployed pause entries are zero/false at N-1, N, and later, all pointers are correct, and the planned migrator/validator explicitly preserve legacy pause routing.
