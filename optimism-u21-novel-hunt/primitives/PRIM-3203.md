# PRIM-3203 — Historical withdrawal proof judged through mutable current registry

PRIM-ID: PRIM-3203

Source contracts: `OptimismPortal2`, `AnchorStateRegistry`.

Exact functions: `proveWithdrawalTransaction`, `checkWithdrawal`, `deleteProvenWithdrawal`, `migrateToSharedDisputeGame`.

Trigger: Change the portal's current AnchorStateRegistry after a withdrawal was proven, then finalize or delete that stored proof.

Attacker-controlled inputs: Permissionless proof/finalization inputs; the registry swap itself requires the migration authority and INTEROP state.

Required state: A stored `ProvenWithdrawal` and a later authorized registry migration.

State mutation: Proof creation stores only `disputeGameProxy` and timestamp. Migration replaces `anchorStateRegistry`; finalization/deletion query the replacement registry.

External calls: `checkWithdrawal` calls the stored game and current registry. Deletion asks the current registry for status/blacklist conditions.

Cross-contract dependency: The historical object is the stored game, but its validity is read from the current `anchorStateRegistry` (`OptimismPortal2.sol:671-725`); migration mutates that pointer (`:528-571`).

Broken or weakened assumption: The verifier for a historical proof is not snapshotted with the proof.

Candidate compositions: Multiple migrations or a registry with overlapping game addresses; divergence between old/new registry retirement and blacklist state; old-lockbox pause routing during migration.

Evidence: `mirror/lane-32/test/NegativeSpace.t.sol::test_deleteProvenWithdrawal_rejectsLiveNonInvalidatedHistoricalObject`: a real OP withdrawal proof has a nonzero timestamp, IN_PROGRESS game, and no current-registry blacklist; deletion reverts `OptimismPortal_DisputeGameNotInvalidated`.

Confidence: High for the temporal coupling; high that the intended first migration is benign.

Reason it may be benign: Upgrade 21 explicitly treats migration-time invalidation and re-proving as intended. The swap is privileged, and the live proof could not be permissionlessly deleted.
