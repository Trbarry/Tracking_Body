PRIM-2302: Finalization is unlock-before-call with transactional rollback or exact relock

Source contracts: OptimismPortal2, ETHLockbox, SafeCall

Exact functions: `finalizeWithdrawalTransactionExternalProof`, `unlockETH`, `callWithMinGas`, `lockETH`

Trigger: Permissionless finalization of a mature valid withdrawal.

Attacker-controlled inputs: The withdrawal's proven sender, target, value, gas floor, and calldata; proof submitter selection.

Required state: Valid mature proof, unpaused system, unfinalized hash, non-CGT for positive value, sufficient pooled lockbox balance.

State mutation: Finalized bit is set before unlock; lockbox sends exact value to portal; portal sets `l2Sender`, calls target, resets it. Successful call consumes value. Failed non-messenger call re-locks exact value. Failed outer messenger call reverts the whole transaction in v9.

External calls: ASR/game validation, lockbox unlock, arbitrary all-gas target call, optional lockbox relock.

Cross-contract dependency: Lockbox relies on portal `l2Sender`; portal relies on EVM revert atomicity and SafeCall return semantics.

Broken or weakened assumption: Value is transiently in the portal before `l2Sender` is set, but no attacker-controlled callback occurs in that interval.

Candidate compositions: Target reentrancy; nested deposit; messenger outer/inner failure distinction; future gas-rule changes.

Evidence: v9 `src/L1/OptimismPortal2.sol:577-665`; `src/L1/ETHLockbox.sol:153-178`; `src/libraries/SafeCall.sol:121-171`; 638.177259920741319864 ETH real-withdrawal fork trace and three etched reentrancy/failure tests.

Confidence: High for deployed ordering and arithmetic; modeled-only for substituted target behavior.

Reason it may be benign: `l2Sender` plus the finalized bit blocks nested finalization, and any later revert restores both the unlock and finalized bit atomically.
