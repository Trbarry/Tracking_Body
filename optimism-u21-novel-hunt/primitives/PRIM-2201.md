PRIM-ID: PRIM-2201 — privileged same-version reset-and-replay

Source contracts: `OPContractsManagerUtils`, `StorageSetter`, OZ `Initializable`, `ProxyAdmin`.

Exact functions: `OPContractsManagerUtils.upgrade`, `StorageSetter.setBytes32/getBytes32`, `ProxyAdmin.upgrade/upgradeAndCall`, each target `initialize`.

Trigger: An OPCM upgrade installs StorageSetter, clears one packed initializer byte, atomically calls the target's same-version initializer, checks that no OZ-v5 namespaced state was written, and restores the implementation.

Attacker-controlled inputs: None for an unprivileged attacker. ProxyAdmin owner controls target, implementation, initializer calldata, slot, and byte offset through the privileged upgrade path.

Required state: Target is a ProxyAdmin-managed proxy whose initializer uses OZ-v4 `_initialized` storage.

State mutation: Temporarily changes implementation; masks one byte in an arbitrary packed word; initializer rewrites configuration; restores implementation with the same final init version.

External calls: ProxyAdmin calls the proxy/initializer; initializer-specific calls may follow.

Cross-contract dependency: OPCM's caller-supplied slot/offset must match the target's inherited Initializable packing and proxy variant.

Broken or weakened assumption: “The same initializer version can never execute again” is false during an authorized OPCM upgrade; safety depends on atomic access control and complete initializer replay.

Candidate compositions: Wrong reset offset corrupts a neighbor byte; an initializer omits a retained field; an initializer external call observes a partially replayed configuration.

Evidence: `op-v9.0.0/packages/contracts-bedrock/src/L1/opcm/OPContractsManagerUtils.sol:352-386`; `.../src/universal/StorageSetter.sol:10-42`; receipt `Initialized` events at the same versions; `U21_STORAGE_LAYOUT_DIFF.md`; `StorageBoundaryTest.test_publicReinitializersAreClosedToUnprivilegedCaller`.

Confidence: High.

Reason it may be benign: The path is ProxyAdmin-owner gated and atomic; U21 used the correct offsets, replayed the intended fields, and left every public initializer closed.
