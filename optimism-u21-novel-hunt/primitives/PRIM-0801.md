PRIM-ID: PRIM-0801 — L2 budget (old constants) vs L1 v9 relay requirement: forced "finalized + failed" band
Source contracts: L2CrossDomainMessenger 2.2.1 (live predeploy 0x42…07, not upgraded), L1CrossDomainMessenger 2.13.0
  (proxy 0x25ace71c…, impl 0x7d4Ec7fB…), OptimismPortal2 6.1.0, ResolvedDelegateProxy, SafeCall.
Exact functions: L2 `sendMessage` -> `baseGas`; L1 `finalizeWithdrawalTransactionExternalProof` ->
  `SafeCall.callWithMinGas` -> `relayMessage` -> `SafeCall.hasMinGas(_minGasLimit, 135,000 + 15,000)`.
Trigger: anyone finalizes a proven, matured messenger withdrawal supplying only the minimum gas the portal accepts
  (`gasleft*63 >= gasLimit*64 + 63*40,000`).
Attacker-controlled inputs: the transaction gas limit of the finalize call; the choice of whose withdrawal to finalize.
Required state: victim message with `minGasLimit` >= 7,317,200 (budget from live L2CDM 2.2.1) or >= 5,756,900
  (budget from the pre-2.2.x formula `285,000 + 16*len + 64m/63`, still in flight), and small enough to fit an L1 tx.
State mutation: `finalizedWithdrawals[hash] = true`, `failedMessages[msgHash] = true`, `_value` moved lockbox ->
  portal -> L1CDM; target not called.
External calls: portal -> L1CDM proxy -> AddressManager, impl; no call to the target.
Cross-contract dependency: L2 `baseGas` charges 40,000 + 5,000 for what L1 now reserves as 135,000 + 15,000; the
  105,000 difference is taken from the 200,000 constant overhead, of which ~40.3k is the real pre-check cost and
  `gas/64` is withheld by the ResolvedDelegateProxy frame.
Broken or weakened assumption: "a relay given exactly `baseGas` executes the target" (GasConstants.sol:16-21) no
  longer holds across versions for large `minGasLimit`. v8 crossing points were 14.03M / 12.47M.
Candidate compositions: none found that loses funds — the message is replayable by anyone with +4k…+11k more gas
  than the portal minimum; replay needs less gas than the finalize did. Only a forced extra transaction.
Evidence: evidence/lane08/measure_tables.md rows 18-20 (margin +36,781 at m=5M, -10,838 at m=8M live, -3,859 at
  m=6M old; v8 +143,371 / +95,752 / +102,731); evidence/lane08/validate_real_tx.jsonl case 20 (real tx, gas
  6,782,692: status 1, successful 0, failed 1); CrossDomainMessenger.sol:265-281; SafeCall.sol:103-109, 162.
Confidence: high (measured on deployed bytecode, transaction semantics, both versions).
Reason it may be benign: it is. Specific-gas griefing with a replayable outcome; suppressed class in LANE_CONTEXT §6.
