PRIM-ID: PRIM-0904 — migrate() topology side effects on legacy per-chain contracts (pause fan-in, orphaned escrow)
Source contracts: src/L1/opcm/OPContractsManagerMigrator.sol, src/dispute/{AnchorStateRegistry,DelayedWETH,DisputeGameFactory}.sol,
  src/L1/SystemConfig.sol, src/L1/ETHLockbox.sol
Exact functions: Migrator.migrate loop (L266-272), _updateDelayedWETHLockbox (L417-430), _updateSystemConfigDelayedWETH
  (L437-467), _migratePortal (L536-555: clears old DGF impls for types {0,1,8,4,5,9,10}; re-inits old ASR with the SHARED lockbox).
Trigger: the planned migrate() for OP Mainnet + Unichain.
Attacker-controlled inputs: none (timing of in-flight games only).
Required state: in-flight games / bonds at migration time (today: OP DelayedWETH 20.66 ETH, Unichain DelayedWETH 21.42 ETH).
State mutation (measured on fork, real OPCM 0x2d91e6F2…, see evidence/lane09-migrate-op-unichain-trace.txt):
  - shared lockbox/ASR/DGF proxies are created by CREATE2 from the Safe (delegatecall context) and administered by
    chain-0's ProxyAdmin 0x543bA4AA… (OP Mainnet); Unichain's ProxyAdmin 0x3B73Fa8d… no longer administers what its portal uses.
  - `UNI SystemConfig.delayedWETH` := OP DelayedWETH 0x1B6DBF05…; Unichain's own DelayedWETH 0x74ad145a… (holding the
    bonds of every in-flight Unichain game) and old DGF/ASR are no longer referenced by any SystemConfig, i.e. later
    OPCM upgrades (which load from SystemConfig) will never touch them again.
  - old ASRs (OP 0x23B2C629…, UNI 0x27Cf508E…) and both old DelayedWETHs now read pause/guardian from the SHARED lockbox:
    one pause of identifier = shared lockbox freezes legacy games + bond withdrawals of BOTH chains.
  - old ASR `retirementTimestamp` is unchanged (1753379243 on OP): in-flight legacy games stay proper and can still
    resolve and call the public `setAnchorState` on the legacy ASR; the portal never consults the legacy ASR again.
  - new shared ASR `retirementTimestamp = block.timestamp` of the migration; every pre-migration game is both
    unregistered (new DGF) and retired for it.
External calls: only OPCM/Utils/Container/StorageSetter, the two ProxyAdmins, SuperchainConfig and the chain proxies
  (trace: no call into any permissionlessly deployed contract).
Cross-contract dependency: pause identifier = lockbox address (U21) x shared lockbox (migration).
Broken or weakened assumption: per-chain blast radius of a Guardian pause; per-chain upgrade coverage of bond escrow.
Candidate compositions: dispute lane — legacy-game bond accounting while the shared identifier is paused for an
  incident on the OTHER chain; un-upgradable legacy DelayedWETH holding bonds.
Evidence: Lane09Migrate.t.sol::test_migrate_op_unichain_realState log output (evidence/lane09-forge-results.txt), trace file.
Confidence: high (state deltas measured).
Reason it may be benign: all of it is consistent with the documented interop trust model; no value moves.
