# PRIM-3101 — Messenger finalization is atomic with the L1CDM low-level call

**PRIM-ID:** PRIM-3101  
**Source contracts:** OptimismPortal2 v9; L1CrossDomainMessenger/CrossDomainMessenger v9; SafeCall; GasConstants.  
**Exact functions:** `OptimismPortal2.finalizeWithdrawalTransactionExternalProof`, `CrossDomainMessenger.relayMessage`, `SafeCall.callWithMinGas`.  
**Trigger:** Finalize a proven messenger withdrawal (`sender == 0x4200...0007`, `target == L1CDM`) with gas near or below the relay boundary, or with a reverting/gas-burning messenger call.  
**Attacker-controlled inputs:** Ordinary finalizer controls transaction gas; withdrawal author previously controls messenger payload/minGas through the L2 message.  
**Required state:** Mature, valid, unfinalized proof. Real post-U21 type-9 fixture used.  
**State mutation:** Portal first sets the global finalized flag and unlocks value, but if the L1CDM low-level call fails v9 reverts, atomically restoring the flag and custody. If L1CDM returns normally, it has recorded `successfulMessages` or `failedMessages`.  
**External calls:** Portal -> ETHLockbox `unlockETH` (for value) -> L1CDM -> final message target.  
**Cross-contract dependency:** A successful low-level L1CDM call must mean the messenger recorded an outcome; the portal only checks call success.  
**Broken or weakened assumption:** None found with the deployed L1CDM. This is the hardened boundary that must remain true under future messenger upgrades.  
**Candidate compositions:** Future L1CDM implementation returns success without writing either mapping; reserve becomes insufficient under a future gas schedule; migration rewires target/proxy semantics.  
**Evidence:** v9 `/home/user/ethereum-optimism/op-v9.0.0/packages/contracts-bedrock/src/L1/OptimismPortal2.sol:603-665`; `/home/user/ethereum-optimism/op-v9.0.0/packages/contracts-bedrock/src/universal/CrossDomainMessenger.sol:256-306`; `/home/user/ethereum-optimism/op-v9.0.0/packages/contracts-bedrock/src/libraries/GasConstants.sol:49-78`. Fork tests `test/MessengerGasBoundary.t.sol`, `test/AdversarialTargets.t.sol::test_v9ReverterAndGasBurner_leaveMessengerWithdrawalReplayable`; 192 sampled real gas values, exact boundary 708,920, zero finalized-neither.  
**Confidence:** High for the current deployed code and tested fixture; bounded gas coverage, not a proof over all payloads/future gas rules.  
**Reason it may be benign:** It is explicitly intended U21 hardening and the tested invariant held.
